# Bluestock Nifty100 Financial Intelligence Platform

> ETL pipeline for transforming Nifty100 financial Excel datasets into a validated SQLite database for analytics and reporting.

---

## Project Overview

This project is being developed as part of the **Bluestock Data Engineering Internship**.

The objective is to build a complete ETL pipeline that:

- Extracts financial data from Excel datasets
- Cleans and normalizes the data
- Validates data quality using business rules
- Loads the cleaned data into SQLite
- Provides a reliable data source for analytics and dashboards
